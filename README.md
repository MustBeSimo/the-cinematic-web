# The Cinematic Web

Companion repository for **The Cinematic Web: Scroll-Driven Web Design with Claude Code, Codex and Reusable AI Skills** by Simone Leonelli (2026).

- Kindle and paperback: https://www.amazon.com/dp/B0HPYP923J
- The skills the book teaches (free, open source): https://github.com/MustBeSimo/web-design-studio

## What is here

| Folder | Contents |
|---|---|
| `sample/` | Chapter 3, *The twelve scroll patterns*, free to read. |
| `examples/bindery/` | The worked example from chapter 6: a pinned hero for a fictional bindery, one self-contained HTML file with the mobile, reduced-motion and no-JS states built in. Live: https://mustbesimo.github.io/the-cinematic-web/examples/bindery/ |
